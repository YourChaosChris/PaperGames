Skyscrapers Rules

A quick reference for how PaperGames plays Skyscrapers - useful if you're rusty, or learning.

The basic idea

The grid
Each cell holds a building's height, from 1 (shortest) up to N (tallest, N being the size of the grid). Around the outside of the grid, some rows and columns carry a clue number just past that edge - not necessarily every row or column, and not necessarily on every side.
Reading the edge clues
A clue gives the number of buildings you'd see looking into its row or column from that side, if a taller building anywhere in front of a shorter one hides it completely from that viewpoint. Top clues look down their column, bottom clues look up it, left clues look right along their row, and right clues look left along it.
The goal
Fill every cell with a height from 1 to N so that each row and each column contains every height exactly once (the same rule as Sudoku's rows and columns, just with no sub-box rule), and every clue shown around the grid matches the number of buildings actually visible from that side.
Entering heights
Select a cell, then pick a height from the pad below the board (or type a digit on a keyboard). A cell showing a dashed outline currently repeats a height already used elsewhere in its row or column - use that as a hint that something needs to change.
Difficulty
Easy, Medium and Hard puzzles use progressively larger grids (4x4, 5x5 and 6x6) with progressively fewer of the edge clues revealed - more heights to juggle at once, but the same two rules throughout.

A worked example

Counting visible buildings
Take a row of four buildings, heights 3, 1, 4, 2, read left to right. Looking in from the left: the 3 is visible first, since nothing taller has come before it. The 1 is shorter than the 3 already seen, so it's hidden behind it. The 4 is taller than everything before it, so it's visible too. The 2 is shorter than the 4, so it stays hidden.
That's 2 buildings visible from the left - the 3 and the 4 - so a left-side clue of 2 fits this row. Looking at the very same row from the right instead (reading 2, 4, 1, 3 in viewing order): the 2 is visible first, the 4 is taller so it's visible too, and both the 1 and the 3 after it are shorter than the 4 already seen, so neither is visible - a right-side clue of 2 as well, here purely by coincidence of this particular row.

Finishing a puzzle

Solved
The puzzle is solved the moment the grid is completely filled in, every row and column has each height exactly once, and every clue around the edge matches its row's or column's actual visible count.
