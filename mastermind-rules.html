Mastermind Rules

A quick reference for how PaperGames plays Mastermind - useful if you're rusty, or learning.

The basic idea

The secret code
At the start of a new game, the computer picks a hidden code of four positions, each set to one of six shapes: circle, square, triangle, diamond, star, or cross. Depending on the difficulty, the same shape may appear more than once in the code.
Making a guess
Tap a slot to cycle it through the six shapes, then tap Submit guess once all four slots show the shapes you want to try. A guess can repeat a shape freely, whether or not the secret code itself has any repeats.
Reading the feedback
Each guess gets back a row of pegs: a black peg for every shape that's both correct and in the right position, and a white peg for every shape that's correct but in the wrong position. For example, if the code is circle-circle-square-triangle and you guess circle-square-square-square, you get two black pegs (the first circle and the third square are both exactly right) and no white pegs - the extra squares in the guess have nothing left over in the code to match. The pegs never say which slots they refer to, so working that out from guess to guess is the whole puzzle.

Finishing a game

Winning
You win the moment a guess earns four black pegs - every shape in exactly the right position.
Running out of guesses
Each difficulty level allows a fixed number of guesses. If you use them all without cracking the code, the game ends there and the secret code is revealed.
Difficulty levels
Easy gives you 12 guesses, but the secret code never repeats a shape. Medium gives 10 guesses and allows repeats, the traditional way the game is played. Hard gives only 8 guesses and also allows repeats, so duplicate shapes are something to watch for.
