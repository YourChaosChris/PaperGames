FreeCell Rules

A quick reference for how PaperGames plays FreeCell - useful if you're rusty, or learning.

The basic idea

A♠ The layout
All 52 cards are dealt face-up into 8 tableau columns from the start - four cards short of a full 7 in the last four columns. Four free cells above the columns can each hold exactly one card, and four foundations (one per suit) are built up from Ace to King.
Moving cards
A card can move onto a tableau column only onto a card exactly one rank higher and the opposite color, or onto any empty column. A run of several cards already stacked in that same descending, alternating order can be moved together as one 'supermove', up to a limit set by how many free cells and empty columns are available to relay them through.
Foundations
A foundation only accepts its own suit, starting with the Ace and moving up one rank at a time. Once a card is on a foundation it stays there - foundations only receive cards, they never give them back to the tableau.

Finishing a game

Winning
The game is won the moment all four foundations are complete, Ace through King. Unlike Mahjong Solitaire's deal here, a FreeCell deal is just a plain shuffle - the overwhelming majority are solvable, exactly like the real game, but PaperGames makes no special guarantee for any one deal.
