Kakuro Rules

A quick reference for how PaperGames plays Kakuro - useful if you're rusty, or learning. Kakuro is sometimes described as "crossword sudoku": instead of letters, every white square holds a digit, and instead of words, the clues are sums.

The basic idea

The grid
The grid is a mix of black clue cells and white fillable cells. Every maximal unbroken line of white cells, reading left-to-right or top-to-bottom, is called a "run". Each run has exactly one clue: the total its digits must add up to.
Reading the clue cells
A black cell shows its sum (or sums) in white digits, split diagonally when it carries two: the number in the upper-right corner is the target for the run of white cells starting immediately to its right (an "across" clue), and the number in the lower-left corner is the target for the run of white cells starting immediately below it (a "down" clue). A black cell with only one clue shows only that number.
The goal
Fill every white cell with a digit from 1 to 9 so that each run's digits add up to exactly its clue - and, just as important, no digit repeats within the same run (a digit can reappear in a run crossing it, just never twice in the same run).
Entering numbers
Select a white cell, then pick a digit from the pad below the board (or type a digit on a keyboard). A cell showing a dashed outline currently repeats a digit already used elsewhere in one of its runs, or belongs to a fully-filled run whose total doesn't match its clue yet - use that as a hint that something needs to change.
Difficulty
Easy, Medium and Hard puzzles use progressively larger grids (7x7, 9x9 and 11x11), which means longer runs and more of them crossing each other - more digits to juggle at once, but the same two rules throughout.

A worked example

Two crossing runs
Say a 2-cell across run is clued 4, and its first cell is also the top of a 2-cell down run clued 3. The across run's two digits must add up to 4 without repeating - only 1+3 or 3+1 can do that (2+2 repeats the 2, so it's not allowed). The down run's two digits must add up to 3 without repeating, which only 1+2 or 2+1 can do.
The shared cell has to be a digit both runs can use. The across run offers {1, 3} for that cell and the down run offers {1, 2} - the only digit in both sets is 1. So the shared cell must be 1, which pins the across run's other cell to 3 and the down run's other cell to 2. That's the whole puzzle solved by elimination alone, with no guessing needed - the same kind of deduction, just repeated many more times over, that solves every larger Kakuro grid.

Finishing a puzzle

Solved
The puzzle is solved the moment every white cell is filled in with every run summing to its clue and no run repeating a digit.
