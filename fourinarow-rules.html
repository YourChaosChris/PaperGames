Four in a Row Rules

A quick reference for how PaperGames plays Four in a Row (also sold as Connect Four) - useful if you're rusty, or learning.

The basic idea

The board and dropping discs
Discs are dropped into one of seven columns on a 6-row board and always fall to the lowest empty slot in that column, like the physical game - no player ever chooses a row directly. Black always moves first.

How a game ends

Winning
The first player to line up four of their own discs in a row - horizontally, vertically, or diagonally - wins immediately.
Draw
If the board fills completely with no four-in-a-row for either side, the game is a draw.
Resignation
A player can resign at any time, ending the game immediately in the opponent's favor.
